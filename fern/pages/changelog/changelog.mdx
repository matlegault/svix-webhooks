This page tracks changes, fixes, and new features across Svix SDK, CLI, and Bridge releases.

<Callout intent="info">
The Svix Server changelog has moved to `server/ChangeLog.md` and the Svix Bridge changelog has moved to `bridge/ChangeLog.md` in the repository.
</Callout>

## Version 2.10.0

- **JavaScript:** Cancel discarded response bodies as part of retry logic.
- **PHP:** `Webhook` now throws `InvalidArgumentException` for an empty or non-base64 secret instead of verifying with an empty HMAC key.
- **PHP:** Fix `Webhook::fromRaw()`, which always threw `ArgumentCountError`; it now also accepts an optional `$tolerance`.
- **Java:** Improve retry logic — retry on HTTP 423 and allow `retrySchedule` to be set.
- **Kotlin:** Improve retry logic — retry on HTTP 423.
- **Ruby:** Fix wrong exception being thrown on some malformed requests in `Webhook#verify`.
- **All SDKs:** Updated to the latest Svix Cloud spec. If you are using the open-source Svix Server, upgrade it to v1.104.0 or later before upgrading the SDK.

## Version 2.9.1

- **JavaScript:** Throw `ApiException` (with the raw response text as `body`) instead of a `SyntaxError` when a 4xx error response body is not JSON.
- **CLI:** Rebuild Docker image for CVE-2026-111497.

## Version 2.9.0

- **Java and Kotlin:** Strip trailing slashes from server URLs.
- **Python:** Retry on HTTP 423 and on I/O errors; add test coverage for `SvixAsync`.
- **All SDKs:** Updated to the latest Svix Cloud API, including ElasticSearch support for Advanced Destinations.
- **C#, Go, Java, JavaScript, Kotlin, PHP, Ruby, and Rust:** Retry requests that fail due to timeouts or other network errors (connection failures, DNS errors, etc.), not just 5xx responses.
- **Go:** Fix the default retry schedule being 50µs, 100µs, and 200µs instead of 50ms, 100ms, and 200ms.
- **PHP:** Send the `svix-retry-count` header on retries and reuse the same `svix-req-id` across retries of a request.
- **JavaScript:** Requests now time out after 15 seconds by default (previously there was no timeout unless `requestTimeout` was set).
- **Go, Java, Kotlin, PHP, and Ruby:** Change the default request timeout to 15 seconds, matching the other SDKs (previously 60s for Go, 30s for PHP, 60s per connect/read/write for Ruby, and no overall timeout for Java and Kotlin).

## Version 2.8.0

- **CLI:** You can now populate a request body from a file using cURL-style `@filename` syntax — for example, `svix streaming events create strm_abcdef123456789 @filename.json`.
- **C#:** Honor cancellation duration wait for retry — use `Task.Delay` instead of `Thread.Sleep` in `Async` methods.
- **Ruby:** Fix `Svix::Webhook.new_using_raw_bytes` to actually accept raw key bytes instead of base64-encoded bytes.
- **Go:** Make `svix.Message().GetOrCreate()` work by changing an accidental pointer receiver to a value receiver, and allow passing `nil` for options.

## Version 2.7.0

- **All SDKs:** Return the new secret from `v1.endpoint.rotate-secret`, `v1.destination.rotate-secret`, and `v1.streaming.sink.rotate-secret`. If you are using the open-source Svix Server, upgrade it to server v1.102.0 before upgrading the SDK.
- **C#:** Fix `TimeoutMilliseconds` option not being respected.

## Version 2.6.2

- **Java and Kotlin:** Fix a bug that broke SDK methods where the underlying HTTP call uses a POST or PUT method and has no HTTP body parameters.
- **Go:** Fix module path so that v2 releases are properly published.

## Version 2.6.1

- **All SDKs:** Updated to the latest Svix Cloud spec.

## Version 2.6.0

- **PHP:** Add support for `destination` and `stream` APIs.
- **PHP:** Add `AutoConfigConsumer`.
- **Python (Breaking):** Drop support for Python 3.9 (EOL). The minimum supported version is now 3.10.
- **Rust:** Revert an accidental breaking change to `AutoConfigConsumer` that required unique access (`&mut self`) instead of shared access (`&self`) on a couple of methods.

## Version 2.5.0

- **All SDKs (New):** Add `autoconfig` API support to create and rotate AutoConfig tokens.
- **Kotlin:** Fix requests with a body not including `content-type`.

## Version 2.4.0

- **All SDKs (New):** Add `destination` API support.
- **All SDKs:** AutoConfig v2 — add support for the updated AutoConfig token format (`auto_v2` prefix).
- **All SDKs (Breaking):** `AutoConfigConsumer.subscribe()` return type changed from `EndpointOut` to `DestinationOut`.
- **PHP (Breaking):** Remove `AutoConfigConsumer` class (reintroduced in v2.6.0).
- **CLI:** In `listen` mode, don't follow redirects returned by the local service.

## Version 2.3.0

- **All SDKs:** Add new streaming sink types.
- **Ruby:** Add missing accessors for `connector` and `streaming` APIs.
- **Ruby:** Accept symbol keys in struct enums (thanks @anishfyi).
- **Ruby:** Fix various small bugs (thanks @clinejj and @anishfyi).

## Version 2.2.0

- **JavaScript (Breaking):** Remove JSON parsing from `Webhook.verify` for consistency with SDKs for other languages.
